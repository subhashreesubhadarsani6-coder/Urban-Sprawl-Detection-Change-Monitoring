# Dataset Directory

This directory stores the Onera Satellite Change Detection (OSCD) dataset shards.

Due to GitHub file size limits and repository size best practices, raw multi-gigabyte parquet shards and archives are excluded from version control:
- `*.parquet`
- `*.zip`

### Structure
For full dataset schema details, split manifest information, and downloading/preparing the dataset, refer to [DATASET_INVENTORY.md](../docs/DATASET_INVENTORY.md).
